## Running the Projects

The .NET SDK is required to run the C# projects.

To run a project, navigate to the project directory and use:

```
dotnet run
```

Example:

```
cd Topic1/PracB/TodoApp
dotnet run
```

To run the unit tests:

```
dotnet test Topic1/PracB/TodoApp.Tests
```
